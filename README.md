# Пошук зразка в рядку: наївний, КМП, Боєр–Мур

Лабораторна робота №2 з дисципліни «Алгоритми та складність», **варіант 2**.

> Реалізуйте три алгоритми пошуку зразка в текстовому рядку: наївний, Кнута-Морріса-Пратта (КМП) та Боєра-Мура (з обома евристиками: поганого символу та хорошого суфікса). Порівняйте їхню ефективність (кількість порівнянь символів та час роботи) – виконайте пошук зразків різної довжини (5–50 символів) у двох середовищах: 1) випадковий бінарний зразок у випадковому бінарному тексті; 2) випадкове слово у природомовному тексті цією мовою (текстовий файл розміром від 1 МБ). Проаналізуйте, як довжина зразка та розмір алфавіту впливають на швидкість кожного алгоритму.

## Коротко

- **Наївний алгоритм** звіряє зразок з кожною позицією тексту.
- **КМП** будує префікс-функцію і завдяки їй ніколи не повертається назад по тексту.
- **Боєр–Мур** порівнює зразок справа наліво. Зсув він обирає як максимум двох евристик: поганого символу та хорошого суфікса (сильна версія).
- Кожен алгоритм має дві версії (шаблонний параметр `Count`). Версія з лічильниками рахує порівняння символів під час пошуку та попередньої обробки. Версія без лічильників потрібна для чесного заміру часу.
- Перед пошуком текст переводиться з UTF-8 у Windows-1251. Тоді один символ займає один байт, а таблиця поганого символу має 256 елементів.
- Експерименти:
  1. випадковий бінарний зразок у випадковому бінарному тексті;
  2. випадкове слово в українському тексті;
  3. вплив розміру алфавіту (σ = 2…128).
- Природомовний текст: `data/uk_text.txt`, близько 1,36 млн символів українською.

Звіт: [`docs/REPORT.md`](docs/REPORT.md) (і `docs/REPORT.docx`).

## Збірка й запуск

Потрібен компілятор із підтримкою C++20 (g++ або clang++) і `make`. Сторонніх бібліотек немає.

```
make                                 # збирає strsearch і run_tests
make test                            # юніт-тести
./strsearch                          # інтерактивне меню
./strsearch search <файл> <зразок>   # пошук зразка у файлі
./strsearch bench [файл.txt]         # експериментальне порівняння (CSV пишуться в results/)
make check                           # перевірка формату, clang-tidy і тести
```

| Файл | Що в ньому |

| `include/encoding.h`, `src/encoding.cpp` | перетворення UTF-8 ↔ Windows-1251 |
| `include/bench.h`, `src/bench.cpp` | експерименти: генерація зразків, підрахунок порівнянь, замір часу, запис CSV |
| `src/main.cpp` | консольне меню та режими командного рядка |
| `tests/tests.cpp` | юніт-тести, зокрема рандомізована перевірка проти `std::string::find` |
| `data/uk_text.txt` | український текст для другого середовища |
| `docs/REPORT.md`, `docs/REPORT.docx` | звіт; зображення — у `docs/images/` |
